# 20261026_02 历史实测摘要

本页摘录 `jyb_run_20261026_02` 的历史结果，用于说明本次贡献对应版本做过哪些验证。日期为 2026-10-26。它不是本次整理目录重新调用 API 的结果，也不包含后续音色稳定版的测量。

本次仅将该版本功能整合到 `src/openmic/tts_*.py`，并通过 `python -m openmic tts` 使用统一单稿入口。迁移后的导入、路径和 CLI 回归结果以本次测试日志及 CI 为准；不能把下面的历史性能数据写为迁移后的重新测量。

原始依据为该次运行的 `outputs/report/technical_report.md`、`outputs/acceptance/acceptance.json`、`outputs/asr/report.json`、`records/final_validation.json`、测试日志和五 Agent 轨迹。原始生成音频、带本机路径的完整运行记录和私有配置不随代码提交。下列数据保留统计边界，去掉本机绝对路径与账户信息。

## 四条件主实验

声音模型为组内既有 `FunAudioLLM/CosyVoice2-0.5B`，固定配置音色 `alex`，输出 16 kHz、单声道、16-bit PCM WAV。每主题四条件使用相同正文、计划和分段。`baseline` 与 `timing` 复用同一批语音片段，验收确认对应语音 PCM 一致；仅静音控制不同。

| 主题 | baseline 秒数 | timing 秒数 | emotion 秒数 | performance 秒数 |
|---|---:|---:|---:|---:|
| 我的网购经历 | 200.57 | 221.17 | 202.92 | 223.49 |
| 大学食堂选择困难 | 198.34 | 217.58 | 200.43 | 223.62 |
| 期末作业与拖延症 | 206.13 | 236.97 | 222.05 | 243.52 |
| 办了健身卡之后 | 208.93 | 235.85 | 207.63 | 232.19 |
| 小组合作的日常 | 219.97 | 239.89 | 223.10 | 239.91 |

20/20 份主实验音频通过该版本地验收，五份最终完整表演音频均在 180–300 秒内。检查包括 WAV 格式与数据完整性、时长元数据、连续时间轴、计划和正文哈希、声明的控制参数、数字静音区域全零。`timing`、`performance` 共 10/10 份还通过包袱位置的 0.8/2 秒边界规则检查。

这是文件和程序行为验收，不是听感验收。插入零采样的时长不等于严格音素边界间隔，模型内部停顿和弱音可能额外影响听感。固定同一个 `voice` 参数也不保证各片段音色相同。

## 独立无缓存 TTS 性能测量

另对五主题完整表演各测量一次，不使用片段缓存。这些音频与主实验分别保存，因此时长有随机差异。

| 主题 | 最终音频秒数 | 模型输出片段秒数 | 渲染耗时秒数 | 首个完整片段秒数 | RTF | 速度 x |
|---|---:|---:|---:|---:|---:|---:|
| 我的网购经历 | 223.85 | 201.33 | 85.76 | 3.03 | 0.426 | 2.35 |
| 大学食堂选择困难 | 226.61 | 205.69 | 74.75 | 1.53 | 0.363 | 2.75 |
| 期末作业与拖延症 | 250.90 | 217.30 | 91.25 | 3.64 | 0.420 | 2.38 |
| 办了健身卡之后 | 231.69 | 202.49 | 80.25 | 4.37 | 0.396 | 2.52 |
| 小组合作的日常 | 246.39 | 224.67 | 81.99 | 2.34 | 0.365 | 2.74 |

有效无缓存测量 5/5。合并速度为 `sum(模型输出片段时长) / sum(渲染耗时)`，约 **2.54x**；最小单主题值约 2.35x。RTF 为相反比值，小于 1 表示这次测量超过实时。

模型输出片段时长排除人工插入的静音，仍可能包含片段内部自然停顿。渲染耗时不含上游 LLM、浏览器播放和渲染返回后的结果保存。首段延迟指首个完整语音片段就绪，不是第一个字节或 token。每主题只有一次测量；不推断服务一般性能、P95 或统计显著性。主实验缓存命中的展示时间不能代替这批冷测试。

## 真人评价与已知问题

匿名材料已准备：20 个正式音频样本、8 份听众评分表，另有短稿 pilot 材料。历史验收时有效已填写评分行为 **0**，模板为空。自然度、幽默度、停顿、重音和情绪表达的真人评价均待完成，没有 MOS 数字和提升结论。

用户之后试听反馈：02 版同一音频中会出现音色变化，情绪句有时明显换成另一种声音，句后再恢复。这是本版本已知问题；严格的 WAV 和停顿检查没有检测或解决它。新仓库保留本次指定的 02 版实现，不能据上述文件验收或 ASR 表格宣称声音已稳定。

本次不包含后续参考音色锚定、整篇连续母带、局部 WSOLA 韵律、说话人嵌入分析或 Whisper 对齐等改动。没有训练 TTS、没有 learned latent、没有文本/音频双流式；Linux/AutoDL 只提供复现路径，历史没有在真实实例运行。CosyVoice2 是组内选择的课程替代后端，不应表述为已使用课程示例中的 ChatTTS 或 VALL-E X。
