# jyb 固定 TTS 对照稿

这五份原创稿件为本次 TTS 对照与现场演示准备，使用同一组结构标签和有限情绪标签。

它们是固定测试稿，**不是五 Agent 工作流生成结果，也没有经过真人听评验证，不能宣称已经证明好笑或改善表演质量**。本次仅验证文本协议；真实音频时长、发音、重音、情绪和听感需另外合成后实测。

| 文件 | 主题 |
|---|---|
| shopping.txt | 我的网购经历 |
| canteen.txt | 大学食堂选择困难 |
| deadline.txt | 期末作业与拖延症 |
| fitness.txt | 办了健身卡之后 |
| groupwork.txt | 小组合作的日常 |

每个完整语音段独占一行；铺垫和包袱分别标记。编译器在包袱/回调前后添加默认 0.8 / 2.0 秒停顿。相同稿件应统一用于 baseline、timing、emotion、performance 对照条件。
