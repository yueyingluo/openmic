# OpenMic 中文幽默文本评分说明（试标版）

我们希望了解读者对中文生活类短段的真实感受。每篇文字独立评分，没有需要猜中的标准答案。

请只考虑文字本身，不设想特定演员的表演。先读完整段，再回答“你觉得这段文字有多好笑”。不要和其他评分者讨论，也不要参考自动模型的分数。

| 分数 | 含义 |
| --- | --- |
| 1 | 没有感到好笑；即使看得出在讲笑话，也可以给1分 |
| 2 | 略有趣，但笑点较弱或牵强 |
| 3 | 有明确、自然的笑点，有一定幽默感 |
| 4 | 包袱有效、有新意，明显好笑 |
| 5 | 很好笑，铺垫与揭底配合出色，明显强于一般段子 |

不要求真的笑出声。文笔好、篇幅长、格式完整不一定代表好笑。夸张和荒诞本身也不是缺点，只看它们有没有产生效果。

另外记录：

- 是否看出作者在尝试制造幽默：是／否／不确定。
- 是否理解文本：理解／部分理解／不理解。
- 可选评论：最有效或最牵强的位置，以及你不理解的背景。

如果看懂但不觉得好笑，请给低分；如果因缺少背景无法判断，可以留空分数并说明原因。不要填0。请保留自己的真实判断，不必与他人一致。

每次建议最多24篇，疲劳时休息。同一主题可能有不同文本，仍分别评价。出现熟悉的稿件可备注“之前看过”。

配对题请比较A、B哪个更好笑，可以选A／B／差不多／无法判断。两篇都不好笑也可以选差不多。不要仅因为A先出现就优先选择。

后台记录字段：匿名评分者ID、匿名样本ID、轮次、呈现顺序、幽默评分、意图判断、理解情况、可选评论和既往曝光。无需填写真实姓名或联系方式。尚未开始收集评分。
