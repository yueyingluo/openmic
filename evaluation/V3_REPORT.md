# 评估 V3：文本准确率、表达与可懂度

2026-10-27。文本确认集为 **187/407 = 45.95%**，未达到 50%。同集合多数类及开发选出的轻量分类器均为 **173/407 = 42.51%**；差值区间包含零。可保留为有限的文本评分信号，不能宣称稳定优于轻量模型。

声音侧分别拟合公开人工的表达适切性与可懂度标签，不把两者当作好笑程度。完整作品的实验性接口、声音输入覆盖检查与真人幽默有效性是不同验收项。没有新真人盲评时，后者保持待验证。

## 文本：先开发，后冻结，再确认

V2 已查看的 718 条测试全部退出本轮选择与确认。其余 2,606 条来自原训练/验证池，沿用排除 CFunSet 规范化精确重合组的版本。用固定 BGE 嵌入做 80 个语义簇，再合并被旧重复组、字符 3—5gram 余弦 ≥0.70 或嵌入余弦 ≥0.92 连通的簇；按簇成员身份哈希划分。分组不读取等级，簇也不是人工标注的故事/主题，不能保证排除全部同义改写与主题污染。

超过 HFL 编码器 512 token 的完整文本不截断：排除训练 10 条、开发 5 条、确认 1 条，剩余 **1,670 / 513 / 407**。确认覆盖为 407/408 = 99.75%；以下准确率以 407 条可完整输入的共同集合为分母。不能把未覆盖的一条算作预测正确。

所有候选重新从原始公开基座初始化；不加载 V2 已用新确认条目训练的任务 checkpoint。原始 RoBERTa 比较交叉熵、CORN 有序分类、等级期望的 MSE、交叉熵加批内排序损失，两个学习率、三个种子、每种子最多八轮。每个种子按开发 exact accuracy、Spearman、较早 epoch 依次选 checkpoint。再平均三个种子的等级概率，以开发 exact accuracy 选候选。

在确认预测尚未生成时，记录了两轮开发扩展：MacBERT-large 的交叉熵/排序辅助损失，以及 Qwen3-8B 的监督 LoRA 五分类。它们是看过开发结果后的扩展，不能称为全部事先注册。共完成 **14 个配置、42 个种子训练**，最终冻结：

| 开发候选 | 正确/总数 | exact accuracy | Spearman |
| --- | ---: | ---: | ---: |
| RoBERTa + CORN，最终选择 | 225/513 | 43.86% | 0.426 |
| MacBERT-large 最佳配置 | 212/513 | 41.33% | 0.383 |
| Qwen3-8B LoRA 最佳配置 | 211/513 | 41.13% | 0.318 |
| TF-IDF + 逻辑回归，开发选 C | 194/513 | 37.82% | 0.238 |

开发记录在 [text_development_encoders.json](results/v3/text_development_encoders.json)，跨模型冻结记录在 [text_final_selection.lock.json](results/v3/text_final_selection.lock.json)。确认前另记录了执行设备改为本地 CPU FP32的原因：远程大文件传输反复中断，而完整冻结权重已在本地。没有改变模型、样本、等级或 argmax 规则；后续 GPU 推理仅是精度复核，不能再用于选方法。

| 确认方法，同一 407 条 | 正确/总数 | exact accuracy | Macro-F1 | Spearman | 连续分数 MAE |
| --- | ---: | ---: | ---: | ---: | ---: |
| 冻结 CORN 三种子 | 187/407 | **45.95%** | 0.284 | 0.366 | 0.694 |
| 冻结轻量分类器 | 173/407 | 42.51% | 0.119 | 0.292 | 0.764 |
| 训练多数类（3 档） | 173/407 | 42.51% | 0.119 | 不适用 | 0.708 |

分类为平均等级概率的 argmax，连续分数为等级期望；没有用四舍五入替换分类。CORN 将条件等级概率连乘后还原五档概率。轻量模型在开发集按准确率选择 C=0.1，其确认分类恰好均为 3 档；它的概率期望仍可有不同的排序分数。

按 16 个语义簇做 5,000 次 bootstrap：准确率区间 **[39.80%, 53.56%]**，相对轻量分类器的准确率差值区间 **[−2.40, 8.69] 个百分点**，Spearman 区间 [0.265, 0.443]。置信区间覆盖 50% 不代表达到 50%；点估计还差 17 条正确分类、4.05 个百分点。确认集中 5 档有 9 条，但模型没有预测出 5 档；1 档也只正确 2/45。完整混淆矩阵随 [text_confirmation.json](results/v3/text_confirmation.json) 公开。

**独立性的边界：**这是已使用公开语料的重新分组与重新训练留出，并非新收集的外部盲测。407 条中 353 条来自原训练、54 条来自原验证；旧结果也影响了研究方向。本轮冻结候选没有用新确认条目拟合，确认结果未用于调参，但不能抹去旧语料已被使用的历史。分区审计见 [text_lineage_audit.json](results/v3/text_lineage_audit.json)。CMHL 每条仅一位原标注者，未知预训练污染仍未排除。不能把这组成绩升级成新读者、完整稿件或项目真人验证。

## 声音表达：新故事留出，有有限关联

CEAEval 使用人工表达适切性标签 0—5。V2 开发/测试涉及的故事全部退出新确认；剩余 52 个故事再按故事身份哈希固定划分，得到 36/8/8 个故事、1,360/388/320 条完整 3—20 秒句段。每条完整解码、重采样到 16 kHz，检查特征帧覆盖，未采样开头或丢弃结尾。

候选是 14 个波形统计、冻结 Omni 音频编码器均值/标准差、冻结 BGE 台词嵌入、音频与台词拼接；各自仅在开发集选 Ridge alpha。开发最高的是波形统计，故主方法保持它，不能看到确认音频嵌入成绩更高后改选。

| 方法 | 确认 Spearman | 按故事 95% 区间 | MAE，0—5 |
| --- | ---: | --- | ---: |
| 波形统计，开发选定 | **0.326** | [0.093, 0.594] | 1.192 |
| 冻结音频嵌入，固定辅助对照 | 0.500 | [0.315, 0.646] | 1.082 |
| 文字对照 | 0.321 | [0.183, 0.454] | 1.240 |
| 音频与文字拼接 | 0.459 | [0.277, 0.626] | 1.108 |
| 训练均值 | 不适用 | 不适用 | 1.263 |

主方法相对文字对照的 Spearman 差值区间为 **[−0.204, 0.233]**，不能声称确定优于文字。只有 8 个确认故事，区间较宽；未保证说话人独立。统计量可能反映音量、录音与说话方式，不能解释成理解了角色意图。这里没有使用完整小说上下文，也没有复现 CEAEval-M。V2 失败基线与本轮样本、方法均不同，不直接比较差值。

结果与冻结配置见 [audio_confirmation.json](results/v3/audio_confirmation.json)、[audio_selection.lock.json](results/v3/audio_selection.lock.json)。CEAEval 原任务是叙事表达适切性，不能拿该标签验证完整脱口秀的幽默或舞台表演效果。[作者任务说明](https://github.com/wangtianrui/CEAEval)

## 可懂度：使用对应的真人标签

[TMHINT-QI](https://github.com/yuwchen/InQSS) 的 `intelligibility_score` 是听者能辨认的汉字数，句子各含十个字，原量表 0—10；`quality_score` 是另一列音质评分，未作为本模型目标。[原论文](https://www.isca-archive.org/interspeech_2022/chen22i_interspeech.pdf)

公开 ZIP 已核对大小 2,278,236,226 字节、SHA256 和解压 CRC。24,408 条原评分中，4 条缺已发布波形，其余聚合到 14,915 条波形。多数波形只有一位评分者，不把总人数或标注行数称为逐条多人一致性。

原发布 train/test 存在 115 个底层句编号重合。本轮把同句不同说话人、噪声和增强版本放在一起，按底层句编号重新划为 **219/47/48 组，11,178/2,004/1,733 条**。该规则防止同编号句子的变体跨集，但没有原文核对不同编号是否重复；八位说话人均出现在各分区。没有把原发布测试冒充句内容独立测试。

比较波形统计、冻结音频嵌入、两者拼接，只按开发 Spearman/MAE 选 Ridge 参数。初次 float32 拟合出现病态矩阵警告；在确认前保持特征、分区、标签及 alpha 网格，改为 float64 重新开发拟合，保留了原记录。

| 方法 | 确认 Spearman | 按句组 95% 区间 | MAE，0—10 |
| --- | ---: | --- | ---: |
| 音频嵌入与波形统计，开发选定 | **0.462** | [0.391, 0.537] | 1.317 |
| 冻结音频嵌入 | 0.462 | [0.392, 0.536] | 1.319 |
| 简单波形统计 | 0.219 | [0.104, 0.307] | 1.607 |
| 训练均值 | 不适用 | 不适用 | 1.762 |

主方法相对简单波形统计的 Spearman 差值区间为 **[0.155, 0.364]**。这是中文短噪声/增强句的真人可懂度标签证据，不能推广为完整脱口秀听感。发布包没有可核对的逐句文字转录，因此没有伪造文字对照；相应限制随结果保留。区间按固定标签的句组重采样，不覆盖全部听者差异。

完整结果见 [intelligibility_confirmation.json](results/v3/intelligibility_confirmation.json)，数据审计见 [intelligibility_preparation.json](results/v3/intelligibility_preparation.json)。未调用官方已在该数据训练的 InQSS 权重来冒充未知数据验证。

## 完整作品与统一接口

`openmic-evaluate` / `OfflineEvaluator.evaluate(text=..., audio_path=...)` 返回各任务分数、原生量表、版本、覆盖情况、失败项与验证范围。短文本使用冻结 CORN；超长输入明确拒绝，或由调用者显式启用本地 Omni 完整输入实验模式。完整声音的整体幽默与表演表达也走显式实验模式，不把测量音量当作已完成评分。

短句可懂度模型对长音频采用不重叠四秒窗口、尾段不足两秒并入前段，报告逐窗覆盖、最低值和时长加权均值。它读完整波形，但聚合没有完整作品真人标签验证。实验 Omni 的完整输入检查同样只是覆盖证据，其相关 V2 评分基线未通过有效性验证。

接口不给分类概率编造笑点理由。可选文字依据是实际删句前后的模型分数变化，明确标为模型敏感性；不是人类幽默解释。波形依据是实际测量与帧覆盖。各模型失败独立记录，不用可懂度、音质或语言流畅度代替好笑程度。

已实际运行四段既有技术试评作品，共 **548.18 秒**：四条完整波形均解码，整体幽默、表演表达、可懂度各四次数值输出，12 次 Omni 音频特征覆盖检查及四条可懂度分窗覆盖检查均通过，运行失败为零。短文本 CORN 一条，超长完整文本的显式 Omni 实验模式三条。四段仍是本地 Omni 技术试验，不是生产 CosyVoice 配置，生成与实验评审同族的自偏好混杂也仍存在。所有请求仍返回 `partial`，表示科学验证范围有限，不能把无运行异常写成有效性完成。[完整接口记录](results/v3/full_api_integration.json)

安装后的本地 CPU CLI 也实际加载冻结模型、验证 16 个 bundle 文件，返回五档与连续分数、可复算删句敏感性，并明确拒绝超 512 token 输入。它是接口检查，不能充当额外准确率证据。[本地调用记录](results/v3/text_api_verification.json)

固定 Whisper 的 102 条 CEAEval 人工转录核查为 **312/3,046 = 10.24% 字错误率**；四段完整项目音频对原稿为 **405/2,332 = 17.37%**。均读完波形、无解码 token 上限失败；四段原稿是生成稿，不能称为新真人转录。不能把 `1−CER` 当作真人可懂率，也不能确认稿件所有词都清楚读出。25 秒独立分段边界和 ASR 本身都会引入错误。原 EOS 状态检查不适用于库自动移除 EOS 的默认返回，已按底层生成步数/EOS修正并实际复跑，转写误差不变。[人工转录核查](results/v3/asr_human_transcripts.json)、[完整原稿匹配](results/v3/asr_project_fidelity.json)

固定权重的 H100 BF16复核为 **186/407 = 45.70%**，没有取代事先声明的 CPU FP32主结果，更不是第二次独立测试。原始训练服务器、本地和 H100的三个编码器 SHA256 均一致；一次截断音频传输被哈希检查拒绝，修复并核对全部 106 条迁移波形后才验收。[权重与传输核验](results/v3/selected_weight_integrity.json)、[精度复核](results/v3/precision_parity.json)

原私人评分工作簿没有读取或改写。本轮没有项目真人幽默有效性结论，也没有据四段技术样本比较生成条件的优劣。全部自用 GPU 作业结束，调度器已释放资源。

合并版本另作技术复核：同一四段完整作品再次运行失败为零，21 个导出文件哈希及四个真实响应 Schema 通过，没有重新选模型。[合并版本核验](results/v3/release_verification.json)。同时准备了[三维空白听评表与导入分析](V3_LISTENING.md)，分别收集幽默、表达与字词可懂度；实际导出和播放覆盖用独立合成夹具检查。真实四段作品的表仍为空白，没有新增真人评分，不据此改变有效性结论。[听评流程核验](results/v3/listening_workflow_verification.json)
